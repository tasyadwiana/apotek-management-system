# Pharmacy Management System (Desktop - Java)

This application is a desktop-based pharmacy management system developed using Java (NetBeans) and MySQL database.

## Features

* Login authentication
* Medicine data management
* Stock management
* Sales transaction
* Report printing

## Purpose

This project was created as a real-world case study to help pharmacy staff manage medicine inventory and transactions more efficiently.

## Technologies Used

* Java Swing (NetBeans IDE)
* MySQL Database
* JasperReports (for printing reports)

## Status

Completed and working locally.
